# KitKat: ESP32 Wi-Fi Pager Enclosure

A pocket-sized Wi-Fi pager built around an ESP32-C3 SuperMini and a 0.96-inch OLED display. I designed the 3D-printed enclosure.

## Design
- **Rotating-tube opening:** an outer tube rotates over a holder tube to open and close the device
- Internal layout for the ESP32-C3 SuperMini, 0.96" OLED and HW-373 module
- USB-C charging

## Files
- `KitKat.STEP.zip`: full assembly (STEP)
