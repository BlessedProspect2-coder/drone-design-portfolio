## Opening the CAD files
Each project folder holds the full assembly as a compressed STEP file. Unzip it, or use 7-Zip for the `.xz` file, then open the STEP in any CAD tool. Free options: FreeCAD, eDrawings Viewer, or drag it into [3dviewer.net](https://3dviewer.net) in your browser.
